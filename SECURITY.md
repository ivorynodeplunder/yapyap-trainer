# Security Policy

## Supported scope
YAPYAP Trainer is a Windows desktop memory trainer intended for offline/private use.
We treat the following as in-scope security issues:

- Arbitrary code execution outside the target process
- Unsafe deserialization of the config or profile files
- Privilege escalation via the injector adapter

## Out of scope
- Anti-cheat detection reports for online games
- Issues that only reproduce with third-party DLL injectors

## Reporting
Email `security@yapyap-trainer.dev` with a proof-of-concept. Please allow 72h for triage.
